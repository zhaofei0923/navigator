# growth-commercialization.md — 增长与商业化参考

> 本文件记录实施方案中的增长、转化与商业化方向，供后续任务卡拆分使用。
> 它不直接定义权限、计费或会员等级逻辑；相关实现以 `auth-membership.md` 与后续人工确认任务为准。

---

## 1. 增长路径

推荐增长路径：

1. 微信公众号沉淀专业内容与报告入口。
2. 视频号、抖音等渠道分发短内容。
3. 引导至小程序/H5 或 Web 国家数据库。
4. 通过报告申请、AI 咨询、国家数据包形成留资。
5. 由企微、销售或顾问跟进。
6. 转化为会员、报告、咨询或项目撮合服务。

渠道内容必须与平台数据来源保持一致，不得发布无法追溯的政策、项目或风险结论。

---

## 2. 商业化方向

| 类型 | 说明 | 开发前置 |
|------|------|----------|
| 免费版 | 公开国家摘要、部分报告、基础 AI 问答 | Web MVP |
| Pro 版 | 更多国家数据、报告下载、增强 AI 咨询 | 权限/会员人工确认 |
| Enterprise 版 | 团队账号、数据导出、专题服务 | 权限/计费/审计设计 |
| 定制服务 | 国家进入策略、项目撮合、伙伴推荐 | 线索与顾问流程 |
| 国家数据包 | 国家数据、政策、项目、伙伴打包售卖 | 报告/下载权限与水印 |

免费版 / Pro / Enterprise 是商业包装名称，不是 `MembershipLevel` 枚举；与 `FREE` / `MEMBER` / `PREMIUM` 的映射必须在权限/会员任务中人工确认。

会员、计费、导出、报告下载属于 AGENTS.md §11 人工确认范围，Codex 不得自行调整权益边界。

---

## 3. 留资场景

MVP 可承接以下留资来源：

- 报告申请。
- AI 咨询结果后的深度服务申请。
- 国家详情页咨询入口。
- 小程序/H5 活动入口。
- 数据包试用或下载申请。

留资接口必须遵守 `api-contract.md` 与 `auth-membership.md`：敏感联系方式加密存储，不在响应或日志中明文回显。

---

## 4. 后续任务拆分建议

- 报告申请与留资来源追踪。
- 报告下载权限与短时效链接。
- 国家数据包资源模型与展示。
- 会员权益矩阵人工确认与服务端门控。
- 销售跟进状态与后台分配。

以上任务不得与 P2 Web 展示混在同一个 PR 中。
