# BASIC60 私有试用运行手册

`BASIC60-PRIVATE-R1`的冻结原始审核包覆盖60国国家档案、2020—2024宏观数据和已收集能源数据。
产品定位是中国企业出海导航仪：中国是出发市场，不属于出海目的地；当前应用展示59个海外目标
市场。该范围限制作用于API查询和产品界面，不删除或重写原始60国审核包、数据库历史和来源链。
它不是正式D4、P0或生产发布。政策、风险、项目、招标、伙伴、搜索、RAG、向量数据库、
Embedding、Reranker以及模型运行服务均不属于V1。

`PBD-BASIC60-PRIVATE-001-A1`允许全部规范化Basic60字段用于私有展示、内部学习和AI、
本地模型及受控外部模型处理。`PBD-BASIC60-PRIVATE-001-A2`把私有试用D1—D4的人工作业
进一步压缩为“一份集中Excel、一个项目批准人、一次精确批准”。A2只批准流程；其生效时
记录的`pending_user_review`是历史状态。`kevin`此后已审核并批准当前精确Excel和规范载荷，
当前验证状态为`private_trial_ready`且`checks=[]`。

## 1. 状态边界

私有试用工具只允许三个结论：

- `not_ready`：集中Excel尚未获批、文件漂移或机器校验失败；
- `private_trial_ready`：`kevin`已批准精确的Excel和规范载荷，仅可进入隔离私有试用；
- `revoked`：私有试用授权已撤销，活动发布必须停止。

正式D1—D4、P0和生产发布始终保持`pending`。`private_trial_ready`不得改称正式D4、P0、
生产或公开发布。

## 2. 唯一人工审核文件

源工作簿和`raw material`目录均为只读。先重建冻结候选：

```bash
uv run navigator-data prepare-basic60-private
```

机器准备必须确认以下冻结数量：

- 60个唯一国家档案；
- 300条宏观年度记录；
- 60条能源记录；
- 2,279个有值观测；
- 61个显式`pending`观测。

随后生成一份集中Excel：

```text
outputs/basic60/BASIC60-PRIVATE-R1_60国基础数据集中审核.xlsx
```

Excel一次展示全部国家档案、宏观数据、能源数据、观测明细、待补项和来源明细。普通产品
页面不显示来源，但本审核文件必须显示来源，方便批准人同时审核数据与来源。文件还必须包含
`机器核对`元数据，用于绑定`release_id`、冻结计数、候选种子、来源清单及
`canonical_payload_sha256`。

缺失值不得改成零：60国电力需求在R1暂不要求补齐、不是私有试用阻断项，继续明确使用
`pending`；斯里兰卡2024年官方汇率也保持`pending`。因此冻结的61项`pending`总数不变。
来源、数值、期间或空值状态如需修改，应先修改只读源之外的受控更新输入，再重新生成候选和
Excel；不要在审核文件中直接改值后沿用旧批准。

## 3. 生成单一审核包

把已生成Excel与当前规范数据/来源载荷绑定：

```bash
uv run navigator-data prepare-basic60-review \
  --input-bundle data/basic60/review/basic60_private_acceptance.json \
  --workbook outputs/basic60/BASIC60-PRIVATE-R1_60国基础数据集中审核.xlsx \
  --output data/basic60/review/basic60_private_excel_review.pending.json
```

该命令不批准数据，也不覆盖已有审核包。生成的`single_excel_review`同时保存：

- Excel的仓库相对路径、文件SHA-256和字节数；
- 完整Basic60数据与来源的`canonical_payload_sha256`；
- 原始目录根哈希、候选种子哈希、来源清单哈希和冻结计数；
- 新建待审包的初始状态`approval: null`。

在机器材料完整且Excel未漂移时，批准前验证结果必须为`not_ready`，并且唯一人工阻断项为
`B60_EXCEL_REVIEW_APPROVAL_PENDING`。A2流程决定本身不能消除该阻断项。

## 4. `kevin`一次批准

项目批准人`kevin`审核Excel中的全部数据和来源。审核通过后，只创建一份批准证据，放在
`data/basic60/evidence`，并由审核包的`single_excel_review.approval`引用其精确SHA-256。

该批准必须：

- `decision=approved`，批准人为`kevin`、角色为`项目批准人`；
- 使用带时区的`approved_at`；
- 覆盖`all_basic60_data_and_sources`；
- 同时逐字匹配审核包中的Excel文件引用和`canonical_payload_sha256`；
- 只授权`private_trial_ready`；
- 明确正式D1—D4仍为`pending`，且不授权P0、生产或公开发布；
- 记录批准依据为实际查看Excel后的明确人工决定。

仅修改Excel中的“审核结论”单元格、口头同意、批准旧版本文件或只批准规范载荷之一，均不能
替代该哈希绑定证据。Excel任一字节或规范载荷任一字段变化后，旧批准自动失效，必须重新生成
并重新审核。

SHA-256 `163a48df8772f5d8a5fc2638240d9f117fec5d0fbb439246319b4fd881e44dd8`和规范载荷
SHA-256 `087f355987d160f828aa70f92eda82b26b2b68bb4f9a673761c18b85ca18b657`。批准后审核包为

## 5. 被取消的私有门槛

A2明确取消以下`basic60_private`人工发布门槛：

- 分开的D1、D2、D3、D4会议；
- 三批分别签收或另行D2批次关闭签字；
- D3无异常时的独立签署；
- 固定180个观测抽样；
- 两名独立数据审核人；
- 数据、质量、合规、技术和项目五角色顺序签署。

这些要求仍可存在于正式D1—D4合同中，但不是本私有试用路径的前置条件，也不得回填为已经
完成。私有路径唯一的人工作业就是`kevin`对精确Excel及规范载荷的一次批准。

## 6. 保留的机器控制

流程简化不取消以下机器控制：

- Excel SHA-256和规范载荷SHA-256冻结；
- 国家、宏观、能源、有值和待补数量校验；
- 原始目录根哈希及来源绑定完整性；
- `解析 → 标准化 → 实体匹配`可重放及异常检测；
- 真实数据与`synthetic_demo`数据库、网络、数据卷、密钥和账号隔离；
- 来源撤销、上一版本回滚及历史保留；
- V1的AI、RAG、搜索、向量和模型运行路由保持关闭。

真实源对象继续保存在仓库外的只读、内容寻址L0卷。L0物化、哈希复核、D3重放及隔离检查
属于机器准备与运行安全，不再产生额外人工签收门槛。401/403、验证码、源结构变化、来源撤销、
原始对象漂移或开放异常仍会使机器校验失败，不能由Excel批准覆盖。

## 8. 界面、API与AI使用边界

国家列表（包括搜索、区域、分页和时间筛选）排除`CHN`；中国与不存在的国家详情接口返回404。
`country=CHN`不进入首页选中项或工具上下文。地球保留中国的普通世界底图轮廓，但不将其
作为可选择、高亮的目标市场。筛选沿用亚洲、中东、欧洲、非洲、北美洲、拉丁美洲、大洋洲。
产品统一表述为“覆盖全球主要新能源市场”，不展示国家覆盖数量或指标数量。
底层`BASIC60-PRIVATE-R1`标识、审核与导入完整性计数、内部API健康检查的存储计数仍按冻结
原始包核验；本轮不改写数据、历史审核包或正式发布状态。

前台按正式产品的呈现方式显示国家、数据与功能入口：不显示审核提示条、`Basic`覆盖等级、
内部发布版本号、逐项发布状态或私有试用说明。数据日期、指标值、单位与统计期继续展示；
空值使用清晰的“暂无数据”等说明，未实现功能标记为“即将上线”。中英文、地球提示、加载与
错误页面采用相同展示口径。该调整仅作用于页面文案和呈现，不改变原始资料、API数据合同、
发布元数据、访问边界或正式D1—D4/P0状态，也不代表已完成生产发布。

真实私有试用只注册国家列表和国家详情GET接口；比较功能及其别名、代理、后端路由和
OpenAPI暴露均已取消，旧比较请求返回404。普通UI/API不返回`source_ref`、
来源URL或来源登记信息；这些信息仅在集中Excel和后台审计链中保留。不得通过仅前端隐藏的
方式保留政策、搜索或AI后端路由。

Excel精确批准后，全部规范化字段可用于私有展示、内部AI、本地模型和受控外部模型处理。
这是数据使用授权，不代表V1要部署模型基础设施。V1不创建向量库、全文检索、知识分块、
Embedding、Reranker或本地/云端模型服务；上述运行组件统一留到V2。

## 9. 人工更新

后续允许人工更新数据。每次更新按同一最短闭环执行：

1. 更新受控输入并重跑`prepare-basic60-private`；
2. 重新生成集中Excel；
3. 运行`prepare-basic60-review`生成新的非覆盖审核包；
4. `kevin`审核新文件并批准新的Excel与规范载荷哈希；
5. 重新验证并生成新的私有发布版本。

不得覆盖旧Excel、旧审核包、旧批准证据或旧发布种子。旧版本保留用于追溯和回滚，失败运行
不得推进活动版本。

## 11. 首页与导航回归检查

- 检查中英文仅三个一级栏目，首页不出现国家数、指标数、来源、`Basic`或内部审核状态。
- 首次进入不预选；从地图和筛选器选择国家，确认筛选项、导航和工具/伙伴链接同步。
- 首屏中英文均无按钮组或筛选器下方国家摘要；三步引导与页尾仍可进入所选国家详情。
- 双击有效国家仅导航一次；拖动、缩放、切换不同国家及点击中国/无数据区域不进入详情。
- 从详情返回首页地图与浏览器后退均恢复国家；无效国家详情返回不可用页面。
- 工具三分类一致，方案分区两子页和旧链接兼容跳转有效，参数与`#project-planning`顺序正确。
- 前端比较代理与后端比较路径/别名均404，OpenAPI不包含比较；国家GET接口继续可用。
- 数据慢或失败时仍能看到首页介绍并进入服务页面，重试不产生合成结果。
- 检查桌面与手机布局、键盘操作，以及实际部署后的单击/双击与选择恢复。
- 执行前端lint、typecheck、测试和构建，后端Ruff、mypy、只读数据validate及pytest回归。
  提交前另按AGENTS完整执行数据生成检查；已有候选或审核输出必须先隔离保护，不能把这些
  固定输出命令当作只读检查覆盖运行材料。

## 12. 国家详情图表与回归检查

国家详情沿用批准Demo的深海蓝、青绿色和同一国家GET接口，不增加数据库字段、后端分析、
数据采集或人工审核流程。顶部保留国家与区域、返回首页地图、出海工具及合作伙伴入口；首都、
语言和货币简洁展示，“更多国家档案”展开多首都及角色、多语言、多币种、多时区、行政区划、
ISO2和数据截至日期。市场评估放在页尾，以紧凑的“即将上线”说明保留，不生成评分。

能源先于宏观展示。深色能源区包含电力装机结构、发电结构两张环形图，青绿色为可再生能源，
灰蓝色为其他电源；总量单独标注，不作为第三个扇区。图表只使用同指标域、同单位、同统计期
的总量与可再生能源数值，“其他电源＝总量－可再生能源”，明细明确标注该计算值。装机单位
为MW、发电量单位为GWh，统计年取自返回指标，不能用页面更新日期代替。

宏观区采用浅色背景和六个独立图表面板，桌面两列、手机单列：

| GDP增长率 | 折线图 |
| 人均GDP | 折线图 |
| CPI通胀率 | 折线图 |
