# Navigator 内部demo设计基准

> 决定：PBD-ACCEL-DEMO-001
> 设计日期：2026-08-22
> 设计稿：`navigator-home-concept.png`、`navigator-compare-concept.png`

## 1. 界面范围

- 主屏：国家选择、五维评分、机会动态、进入理由、主要风险和下一步动作；
- 国家列表与详情：五国合成数据、筛选、评分和信号；
- 国家对比：2—4国选择、五维矩阵、雷达图、关键差异和推荐路径；
- 情报列表：政策与风险、项目与招标、伙伴三类只读演示页；
- 内部访问：共享演示口令，不实现真实用户或企业权限。

## 2. 可见文案锁

首屏允许出现的核心文案：

- `Navigator 新能源企业出海导航仪`
- `首页`、`国家`、`政策与风险`、`项目与招标`、`伙伴`、`国家对比`
- `演示数据 / 非正式结论`
- `出海决策，从国家全景开始`
- `在同一视图中查看市场、政策、项目与合作伙伴信号。`
- `开始国家对比`、`进入国家详情`、`已选 1/4`
- `印度尼西亚`、`越南`、`沙特阿拉伯`、`南非`、`巴西`
- `市场吸引力`、`政策确定性`、`项目活跃度`、`合作伙伴成熟度`、`风险可控性`
- `进入理由`、`主要风险`、`下一步动作`、`机会动态（按时间）`
- `合成演示来源`、`更新时间：2026-08-22`

对比页增加：`国家对比`、`添加国家`、`已选 3/4`、`合成演示评分`、`关键差异`、
`推荐路径`、`优先进入：印度尼西亚`、`备选市场：越南`、`查看依据`。

## 3. 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--navy-950` | `#071c3f` | 顶部导航、主标题 |
| `--navy-800` | `#12335e` | 正文重点、图表轴 |
| `--teal-600` | `#079b98` | 主动作、选中态、正向趋势 |
| `--teal-100` | `#dff5f3` | 选中行背景 |
| `--coral-600` | `#ef4f45` | 风险和负向趋势 |
| `--amber-500` | `#e8a12d` | demo警示条 |
| `--blue-600` | `#1768d4` | 次级系列和焦点环 |
| `--surface` | `#ffffff` | 主背景，必须为真白色 |
| `--surface-subtle` | `#f7f9fc` | 表头和轻分区 |
| `--border` | `#d7dee8` | 分隔线和输入框 |
| `--muted` | `#607086` | 辅助文字 |

- 字体：`Inter, "Noto Sans SC", "Microsoft YaHei", sans-serif`；
- 主标题：40/48，700；页面标题：34/42，700；正文：15/24；控件：14/20，600；
- 8px基础间距；页面水平边距32—60px；圆角4/8/12px；仅主要框架使用轻阴影；
- 动画只用于选中、列表进入和图表变化，150—240ms，并尊重`prefers-reduced-motion`。

## 4. 容器与组件

- `AppShell`：深海军蓝顶部导航、警示条和内容区；
- `CountryRail`：开放式横向分段列表，不使用卡片网格；
- `ScoreStrip`：五个并列指标和一个雷达图；
- `SignalTimeline`：表格化时间线，类型、标题、来源、更新时间和跳转动作；
- `DecisionPanel`：进入理由、风险、动作的单一右侧框架；
- `ComparisonMatrix`：行是维度、列是国家，包含数值、条形和趋势；
- `RadarChart`：一个受控图表框架，不增加装饰图表；
- `IntelligenceTable`：政策、风险、项目、招标和伙伴共用列表骨架。

## 5. 图标与状态

- 使用一致的2px圆角线性图标：罗盘、柱形、盾牌、闪电、伙伴、风险三角、勾选、加号、
  右箭头、日历、信息；
- 选中使用teal填充或下划线；键盘焦点使用2px蓝色外环并保留2px间距；
- 风险不只依赖颜色，必须同时包含图标和文本；
- 所有错误、空态和加载态保留明确文字，不把未采集显示为0。

## 6. 响应式与实现边界

- `>=1280px`保持设计稿的主区+决策侧栏；`768—1279px`将侧栏移到底部；
  `<768px`使用可横向滚动的国家选择和对比矩阵；
- 所有文字和控件由React渲染，概念图不作为运行时界面；
- 前端只通过同源服务端代理调用FastAPI，浏览器不获得后端口令；
- 页面始终显示`演示数据 / 非正式结论`，响应数据必须包含`synthetic_demo`标识。
