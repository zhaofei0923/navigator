## 1. 信息架构

一级导航固定为：

- 首页 / Home
- 全球市场 / Global Markets
- 政策与风险 / Policy & Risk
- 出海工具 / Expansion Tools
- 合作伙伴 / Partners

右上角主按钮为“开始出海规划 / Start Expansion Planning”，跳转`/tools`。国家对比
移出一级导航，`/compare`只承担严格双国辅助比较；旧`/tenders`重定向到
`/tools/tenders`。

首页按以下顺序组织：

1. 价值主张、当前市场和一个主行动；
2. 带完整世界国界轮廓的本地动态地球与市场摘要；
3. AI判断、光储方案、可研草案、投标准备四步连续任务链；
4. 安静的合成数据边界说明。

每个视口只显示当前语言，禁止中英文并排造成信息密度翻倍。

## 2. 双语与全局状态

- 顶部使用`中 / EN`分段切换；登录页也提供同一控件；
- 默认`zh-CN`，选择保存在`navigator_locale` Cookie中，不增加语言路径前缀；
- `<html lang>`、页面标题、描述、日期、数字、容量、金额和单位随语言变化；
- 语言切换重新请求当前`locale`数据，但保留选国、表单和筛选状态；
- 所有页面持续显示当前语言的合成数据提示：
  - 中文：`演示数据 / 非正式结论`
  - 英文：`Demo Data / Non-official Conclusions`
- 不加载外部字体，不调用在线翻译；英文内容来自仓库内词典与fixture。

## 3. 视觉方向

目标是“多边机构的信息秩序 + 新能源科技感”：可信、克制、开放，避免高密度运营
驾驶舱、过多统计卡和装饰性图表。

## 4. 核心组件

- `AppShell`：深海军蓝顶部导航、语言切换、主行动、持续Demo边界条和页脚；
- `CountryGlobe`：本地WebGL世界国界面层、悬停高亮、合成信息提示、缩放/放大、单一
  键盘市场选择器和无WebGL回退；全球市场页不在地球下方重复列出首期五国；
- `ToolPageShell`：四项出海工具共用的当前步骤、市场上下文、边界、输入、结果和
  下一步框架；
- `ScoreStrip`与`RadarVisualization`：国家详情和双国比较的受控评分表达；
- `IntelligenceListPage`：政策、风险、机会和伙伴共用的低密度列表框架；
- `LanguageSwitcher`：登录前后一致的`中 / EN`控件。

动态地球不请求在线地图、纹理或瓦片服务。世界国界轮廓作为仓库内置的展示几何，
不作为业务证据或法律边界。地球支持旋转、拖动、国家面悬停高亮、滚轮/触控与按钮
缩放，以及全屏式放大；系统减少动效时停止自动旋转。WebGL不可用时，单一键盘市场
选择器仍提供选国与进入详情能力。

## 5. 四项工具的表达边界

| 工具 | 输入与结果 | 必须显式显示的边界 |
| --- | --- | --- |
| AI出海助手 | 国家、受控问题；市场判断、动作和关联依据 | 模板化预览，不是自由聊天或正式建议 |
| 光储方案 | 场景、容量、储能时长；概念配置、假设和风险 | 不输出IRR、LCOE或工程级设计 |
| 可研报告 | 国家、项目类型、章节；结构化草案 | 只预览，不生成正式PDF/DOCX |
| 项目招标 | 国家、行业、阶段、关键词；合成招标详情 | 非实时来源，不代表真实采购机会 |

表单不得要求真实客户资料、项目秘密、个人信息或受限材料。

## 6. 状态、无障碍与响应式

- 风险和状态不能只依赖颜色，必须同时包含图标或文本；
- 键盘焦点使用清晰的2px外环，交互元素保持可读标签；
- 加载、空态和错误状态均按当前语言显示，未采集不得伪装为0；
- `>=1180px`使用宽屏双列或四列任务；工具结果约40%输入、60%结果；
  `840—1179px`压缩为两列或按内容单列；
  `<840px`使用单列和移动导航；
- 390px视口不得出现页面级横向溢出；必要的宽表只能在组件内部滚动；
- 日期、数字、容量、金额和单位必须使用当前locale格式化；
- 任何运行时网络请求只能指向本机Web、API和数据库链路，不得请求外部地图、字体、
  翻译或模型服务。

## 7. 治理边界

所有组件和API内容只能使用仓库自有`synthetic_demo` fixture。v2界面不表示D1—D4已
完成，不构成专业结论，不授权真实来源、真实用户、外部集成、公网部署或生产采用。
