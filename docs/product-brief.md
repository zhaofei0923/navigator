# product-brief.md — 产品与 Web 体验 Brief

> 本文件把《新能源企业出海导航仪项目初步实施方案》与后续产品决策沉淀为 Web 开发依据。
> 若与 `data-schema.md`、`coverage-levels.md`、`api-contract.md` 冲突，以后者的数据/接口契约为准；本文件只定义产品范围、信息架构与体验验收。

---

## 1. 产品定位

新能源企业出海导航仪是面向中国新能源企业的全球国家数据库与 AI 决策服务平台。

产品核心不是单个国家专题页，而是一套可复制的全球国家情报模板：

- 国家维度统一，所有国家共用 10 个分析模块。
- 数据深度按 Basic / Standard / Complete 覆盖等级渐进。
- 印尼是首个 Complete 样板国家，用于验证模板、数据治理、AI 问答与报告转化。
- Web 是主产品形态，小程序/H5 是轻入口与转化入口。

---

## 2. MVP Web 信息架构

MVP 顶层导航固定为四个板块：

| 板块 | 目标 | 核心内容 | 验收重点 |
|------|------|----------|----------|
| 首页 | 建立全球出海情报入口与专业可信感 | 全球概览、重点国家、机会/风险信号、报告入口、AI 咨询入口 | 首屏能看到产品价值与重点数据，不堆满表格 |
| 国家 | 浏览全球国家数据库 | 地图/列表、地区/行业/技术/覆盖等级筛选、国家卡片、国家详情 | 国家结构统一，未建设模块显示 `BUILDING` 占位 |
| AI 咨询 | 基于已审核数据回答企业问题 | 国家/行业/模块筛选、问答、来源、更新时间、风险提示 | 严守 AI 红线，无数据返回 `ai.noData` |
| 报告 | 承接转化与会员权益 | 报告库、国家数据包、下载/申请、留资入口 | 权限服务端校验，未授权不暴露真实下载地址 |

国家对比不进入 MVP 顶层导航，作为后续能力保留；恢复开发前需同步 `roadmap.md`、`api-contract.md` 与 `testing.md`。

## 3. 视觉与交互原则

整体风格参考世界银行、国际能源署等国际机构官网的专业表达，但不复制其品牌资产。

| 原则 | 要求 |
|------|------|
| 国际化 | 中英文信息同等完整；英文版不是中文页面的残缺翻译 |
| 专业可信 | 用清晰层级、可靠来源、更新时间、覆盖等级建立信任 |
| 科技感 | 可使用地图、指标条、状态徽章、数据可视化与 AI 工作流表达，但避免装饰性堆叠 |
| 低密度重点展示 | 首屏与卡片只展示决策信号，详细数据进入详情或报告 |
| 模板化 | 不为印尼或任何单一国家写特例布局 |
| 可扫描 | 重点指标、风险、机会、覆盖状态在 3 秒内可读 |

禁止为了“高大上”牺牲可读性：深色、动效、地图、图表必须服务信息判断。

## 4. 首页内容结构

首页优先展示重点信号，不做数据大表。

建议结构：

1. 全球出海情报首屏：一句定位、主要 CTA、全球地图或数据探索视觉。
2. 重点国家：按覆盖等级与推荐优先级展示少量国家卡片。
3. 机会与风险信号：展示行业/区域层面的少量高价值摘要。
4. AI 咨询入口：提示可询问的国家、行业、政策、风险、项目机会问题。
5. 报告入口：展示可下载或可申请的报告与国家数据包。

首页不得硬编码国家名称；示例国家来自接口或 seed 数据。

## 5. 国家板块体验

国家列表与地图是同一数据入口，必须支持：

- 地区筛选。
- 行业标签筛选。
- 技术标签筛选。
- 覆盖等级筛选。
- 中英文同步切换。

国家卡片只展示决策摘要字段：

- 国家名称、地区、覆盖等级。
- 简短摘要。
- 模块覆盖状态。
- 更新时间。
- 派生的重点信号，如机会、风险、政策友好度或推荐优先级。

重点信号的计算与展示规则见 [scoring-framework.md](./scoring-framework.md)。如需将这些信号落库，必须先走 `data-schema.md` 与 Prisma schema 的人工确认流程。

## 6. 国家详情体验

详情页使用统一模板渲染 10 个模块：

1. `market-overview`
2. `policy`
3. `risk`
4. `opportunities`
5. `projects`
6. `partners`
7. `chinese-companies`
8. `entry-strategy`
9. `ai-advisor`
10. `reports`

模块状态驱动展示：

- `PARTIAL` / `COMPLETE`：展示已发布数据。
- `BUILDING`：展示建设中占位，不报错、不空白。
- 缺少当前语言文本：按 `pickLocale()` 降级，并标注未翻译。

详情页可以参考“国家工作台”体验：顶部给出国家摘要、覆盖等级、更新时间、关键机会/风险，再进入各模块。

## 7. AI 咨询体验

AI 咨询板块只呈现经过审核且允许 AI 使用的数据：

- `reviewStatus = published`
- `aiUsable = true`
- `credibility != UNVERIFIED`

回答必须包含：

- 与当前语言一致的回答。
- 来源列表。
- 引用数据更新时间。
- 风险提示。

检索不到有效数据时，返回 `ai.noData` 对应文案，不允许臆测。

---

## 8. 报告板块体验

报告板块承接会员与线索转化：

- 免费报告可展示登录后下载或申请入口，下载仍必须走服务端权限校验与短时效绑定用户链接。
- 会员或高级报告只展示可申请/受控下载入口。
- 下载、导出、联系方式等受控资源必须服务端校验权限。
- 报告条目应展示国家、主题、更新时间、覆盖等级、访问等级。

后续“自动生成报告”和“国家数据包售卖”属于商业化增强能力，开发前需补充任务卡与权限验收。

## 9. Web 验收清单

- [ ] 顶层导航为：首页 / 国家 / AI 咨询 / 报告。
- [ ] UI 文案全部走 i18n key，`zh-CN` 与 `en` key 完全对齐。
- [ ] 业务展示文本使用 `LocalizedText`，缺失语言有降级标记。
- [ ] 不为单个国家写特例页面、特例字段或硬编码国家名。
- [ ] 国家详情 10 模块模板一致，`BUILDING` 状态可见且不报错。
- [ ] 页面信息密度适中，首屏突出重点信号，不用大表堆满内容。
- [ ] AI 与报告入口符合 `ai-advisor.md`、`auth-membership.md` 红线。
- [ ] 桌面与移动端关键流程通过 Playwright E2E。
