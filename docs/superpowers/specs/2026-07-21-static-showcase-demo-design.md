# Navigator 静态对外展示与产品 Demo 设计

## 1. 目标

交付一个可供投资人和合作方直接查看的 Navigator 对外展示页，同时提供可操作的产品体验。页面必须是单个 HTML 文件，双击即可打开，不依赖后台、数据库、构建工具、网络连接或第三方 CDN。

页面只展示平台能力、UI 样式和 UX。所有业务数据均为虚构示例，不读取、不复制、不披露仓库中已发布的真实国家数据。

## 2. 受众与成功标准

主要受众是潜在投资人、产业合作方和渠道合作方。一次演示应同时回答三个问题：

1. Navigator 解决什么出海决策问题。
2. 平台可以提供哪些国家情报、分析和数据产品能力。
3. 成熟产品的界面与核心操作体验是什么样。

成功标准：访客无需讲解即可理解平台定位；演示人员可以在页面内完成市场筛选、国家切换、模块浏览、AI 模拟问答和报告预览；中文与英文展示完整一致；断网后页面仍可使用。

## 3. 交付边界

### 3.1 包含

- 单文件 `navigator-demo.html`。
- 中英文一键切换，默认中文。
- 官网式价值叙事与交互式产品驾驶舱。
- 虚构市场、指标、机会、风险、模块状态和模拟来源。
- BASIC、STANDARD、COMPLETE 三种覆盖深度的产品展示。
- 十个固定分析模块的统一导航与状态展示。
- 本地模拟的 AI 顾问和报告预览。
- 桌面端与移动端响应式布局。
- 键盘操作、可见焦点和减少动态效果支持。

### 3.2 不包含

- 真实国家数据或现有 canonical publication 的内容。
- API、数据库、用户系统、后台管理或服务端逻辑。
- 真实 AI 推理、真实报告下载或访客信息采集。
- 外部字体、图片、脚本、样式或分析服务。
- 对现有统一数据模型、AI 检索边界、权限或计费逻辑的修改。

## 4. 信息架构

页面采用“官网叙事 → 产品驾驶舱 → 能力与合作”的单页结构。固定顶部导航提供锚点跳转和语言切换。

1. **首屏**：品牌、核心价值、主要操作入口、抽象全球能源情报视觉和演示数据声明。
2. **平台价值**：说明分散信息、跨语言判断和来源可信度等问题，以及平台对应能力。
3. **统一国家模型**：展示所有国家共用十个分析模块和渐进覆盖等级。
4. **市场驾驶舱**：虚构区域视图、筛选器、市场列表和决策信号。
5. **国家工作台**：统一详情模板、机会与风险、趋势与来源、十模块状态。
6. **AI 出海顾问**：典型问题、自定义输入、分析状态、带模拟来源和风险提示的本地回答。
7. **报告与数据产品**：报告类型切换、封面、目录、关键洞察和交付形式预览。
8. **可信机制**：双语、来源、更新时间、可信度、审核状态和 AI 可用边界的产品表达。
9. **合作价值**：面向投资人和合作方的价值总结与无数据采集的联系入口。

顶部导航包含平台能力、产品演示、AI 顾问、数据产品、合作价值和语言切换。点击导航平滑滚动到对应区域。

## 5. 首屏设计

首屏保持低密度，只允许出现：

- Navigator 品牌名称和全球新能源市场情报定位。
- 核心价值句：“把分散的全球市场信息，转化为可执行的出海决策”及等义英文。
- “体验产品 Demo”和“了解平台能力”两个入口。
- 一幅通过内嵌 SVG/CSS 实现的抽象全球能源情报视觉。
- “本页面全部数据均为虚构演示数据”的持续可见标识。

首屏不使用真实国名、真实统计数字、装饰性标签堆叠、霓虹渐变或模拟系统控件。

## 6. 核心交互

### 6.1 市场驾驶舱

- 内置三个虚构市场，使用中立名称，避免与真实国家对应。
- 可按虚构区域、行业、技术方向和覆盖等级筛选。
- 选择市场后，市场规模、增长趋势、政策友好度、风险等级、推荐优先级、机会摘要和模块覆盖同步更新。
- 无筛选结果时显示明确空状态，并提供重置入口。
- 区域视图使用抽象形状或虚构地图，不暗示真实地理精度。

### 6.2 国家工作台

工作台始终使用统一结构，包含固定十模块：

1. `market-overview`
2. `policy`
3. `risk`
4. `opportunities`
5. `projects`
6. `partners`
7. `chinese-companies`
8. `entry-strategy`
9. `ai-advisor`
10. `reports`

BASIC、STANDARD、COMPLETE 只改变内容深度和模块状态，不改变页面结构。未覆盖模块显示“数据建设中 / Data Building”，不得出现空白或错误状态。

趋势、结构和风险图使用内嵌 SVG/CSS 绘制，不引入图表依赖。图表必须提供文本标签或可访问描述。

### 6.3 AI 顾问模拟

- 提供三个可点击的典型问题和一个自定义输入框。
- 提交后短暂显示本地分析状态，再根据关键词返回预设演示答案。
- 每个匹配答案均包含模拟来源、模拟更新时间和风险提示。
- 无匹配内容时显示“演示模式暂无对应数据”，不得生成随机结论或伪装成真实 AI。
- 输入仅在当前浏览器内处理，不上传、不持久化。

### 6.4 报告预览

- 可切换市场进入简报、政策追踪和机会项目清单等虚构产品类型。
- 预览封面、目录、关键洞察和交付形式。
- 不提供真实文件或真实下载地址；主要操作明确标记为演示预览。

## 7. 双语设计

- 支持 `zh-CN` 和 `en`，默认 `zh-CN`。
- UI 文案与虚构业务文本分层组织，但都内嵌于单文件脚本中。
- 两种语言的 key 和数据字段必须完全对齐。
- 切换语言时，导航、标题、说明、市场名称、摘要、图表标签、模块状态、AI 问题与答案、报告内容同步更新。
- 使用 `localStorage` 保存语言和最近选择；访问受限时静默回退到中文和默认市场。
- HTML 根元素的 `lang` 属性随语言同步切换。

## 8. 视觉系统

- **气质**：国际机构式的专业、可信、清晰，兼具克制的科技感。
- **颜色**：深海军蓝为主色，白色为基础背景；能源绿色用于机会、增长与可用状态；琥珀色和红色分别用于提醒和风险。
- **排版**：只使用系统无衬线字体栈，确保离线一致性；标题紧凑，正文强调可读性。
- **容器**：优先使用开放式布局、数据横栏、列表和少量重点面板，不使用重复的圆角卡片网格。
- **动效**：只用于模块切换、数字变化、图表进入和滚动反馈；遵守 `prefers-reduced-motion`。
- **响应式**：桌面端采用宽屏数据工作台，移动端变为纵向模块流；关键操作在窄屏下保持可见和可触达。

## 9. 数据与安全边界

所有示例内容在源码中明确标记为 demo fixtures，并使用虚构市场名称、虚构组织名称、虚构来源标题和非真实链接。页面不得读取仓库中的真实 seed、canonical JSON、API 响应或构建产物。

以下位置持续显示演示声明：首屏、驾驶舱标题区域、AI 回答、报告预览和页脚。声明应表达“虚构演示数据，不构成投资或市场进入建议”。

联系入口只使用可替换的普通 `mailto:` 链接或静态二维码占位，不提交表单、不使用追踪脚本、不保存个人信息。

## 10. 技术结构

最终文件内部按以下职责划分：

- 语义化 HTML：页面区块、导航、表单、按钮、状态区域和无障碍文本。
- 单一内嵌 `<style>`：设计 token、布局、组件状态、响应式与减少动态效果规则。
- 单一内嵌 `<script>`：虚构双语数据、状态管理、渲染函数、事件绑定和安全持久化。
- 内嵌 SVG：品牌标记、抽象区域视图、图表和功能图示。

脚本不使用 `eval`、动态代码加载或外部请求。用户输入通过 `textContent` 或等价安全路径显示，不拼接为 HTML。

## 11. 状态与异常处理

- 无筛选结果：展示双语空状态和重置按钮。
- AI 无匹配答案：展示演示模式无数据提示。
- 本地存储不可用或数据损坏：忽略已保存状态并使用默认值。
- JavaScript 被禁用：页面保留价值叙事和静态功能概览，并显示需要启用 JavaScript 才能操作 Demo 的双语提示。
- 图形不可用：关键判断仍以文本和数值呈现。
- 小屏幕：筛选器、模块导航和报告类型允许横向滚动或折叠，但页面主体不得产生整体横向溢出。

## 12. 验收与验证

### 12.1 功能验收

- 双击文件可打开，断网后不影响内容和操作。
- 顶部锚点导航、筛选、市场切换、十模块、语言切换、AI 模拟和报告预览均可操作。
- BASIC、STANDARD、COMPLETE 展示结构一致，覆盖深度与建设中状态正确变化。
- 刷新后保留语言和最近选择；存储受限时正确回退。
- 所有演示内容均带明确虚构声明，无真实国家业务数据。

### 12.2 可用性与无障碍

- 桌面和移动视口无内容遮挡、不可读文本或页面级横向溢出。
- 所有交互可使用键盘完成，焦点清晰可见。
- 控件具有可识别名称、选中状态和必要的 ARIA 属性。
- 颜色不是表达风险或机会的唯一方式。
- 减少动态效果模式下不执行非必要动画。

### 12.3 自动化与独立检查

- 使用静态检查验证文件为单文件交付且不存在外部资源请求。
- 使用浏览器自动化覆盖中文和英文、主要交互路径、桌面与移动视口。
- 检查浏览器控制台无错误。
- 使用独立代码审查验证虚构数据边界、无真实数据泄露、输入安全、响应式和双语字段对齐。
- 在合并前重新运行相关测试和 `git diff --check`。

## 13. 明确不做的扩展

本次不加入后台连接、真实地图、用户登录、真实 AI、真实下载、数据采集、线索表单、访问统计、第三方依赖或多文件构建。任何此类能力均应作为后续独立任务设计和验收。
