## 文件维护规则

- Word与Markdown正文以相同章节编号为唯一映射关系。
- 需求、字段、接口、测试、风险等结构化内容，以Excel附件中的唯一编号为准。
- 需求变更必须同步更新正文、Excel附件和版本记录。
- 未经评审确认的内容标记为“待确认”，不得作为开发冻结基线。
- V1.0 MVP范围以第3章和“功能优先级”工作表共同为准。
